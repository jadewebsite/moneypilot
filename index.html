Security & Privacy
Your Money Data, Fort-Knox Protected
Multiple layers of security keep your financial data completely private and inaccessible to unauthorized parties.
🔐
4-Digit PIN Lock
Set a PIN required every time the app opens. Stored securely using Android's Keystore system.
👆
Biometric Lock
Use fingerprint or Face ID to unlock in milliseconds without typing a PIN each time.
⏱️
Auto-Lock (5 min)
App locks automatically after 5 minutes in background — protects data if you forget to close.
👁️
Hide Balances
One toggle blurs all sensitive amounts on the dashboard — perfect for using in public.
📵
Screenshot Block
Prevents screenshots and screen recordings using Android's secure window flag (WindowManager).
🔥
Firebase Security
All data encrypted in transit (TLS) and at rest. User data is strictly isolated by UID — no shared access.

Hi! I'm Anthony, the sole developer behind MoneyPilot. I built this app from scratch to help everyday Filipinos — including myself — take real control of their personal finances. Too many people live paycheck-to-paycheck not because they earn too little, but because they lack the right tools to see clearly where their money actually goes.

MoneyPilot is my answer: a beautiful, AI-powered, completely free finance tracker built for the Philippine context — Philippine Peso, GCash, local banks, and the financial realities Filipinos face every day.
